# Pepin Place — návrh homepage

Neoficiálny návrh homepage, statická stránka bez build kroku, nič sa nenačítava zo servera.

Koncept „Ovál z ich stola“: tmavá zelená a mosadz z loga Pepin, ktoré majú zlatom vyryté v ovále na stoloch; tenký mosadzný ovál je jediný motív. Stránka stojí na ich jedle (kačica pre dve osoby so štítkami prílohy) a na obedovom menu, ktoré je tu v čitateľnom texte s prepínačom dní namiesto obrázkov na Facebooku. Otvoriť `index.html` v prehliadači (písma sa načítajú z Google Fonts).
